Why I built this / 왜 만들었나
Animation data keeps growing, and finding and applying the right motion eats an animator's time. I built this to make that data easy to find and apply — a tool designed for real production, not for demos.

애니메이션 데이터는 계속 쌓이는데, 필요한 동작을 찾아 적용하는 데 시간이 많이 듭니다. 이 데이터를 애니메이터가 효과적으로, 편하게 쓰도록 만들고 싶었습니다. 목적은 시연용이 아니라 실무에서 쓰기 편한 도구입니다.

What I made: Sonjari Animator Pack / 만든 것
Motion library / 동작 창고 — Stack Biped motions and find them by plain language ("pull out the dash attack"). 바이페드 동작을 쌓아 두고 말로 찾아 입힙니다.
Correction tools / 보정 도구 — Key alignment, center-of-mass and foot-lock checks, using a propose → approve → apply flow. 키 정렬, 무게중심(COM), 발 고정 점검과 보정을 "제안 → 승인 → 적용" 순서로 합니다.
Clip check / 클립 점검 — Flags issues in a clip; the animator confirms or rejects each one. 클립의 문제 후보를 짚으면 애니메이터가 맞다/아니다를 판정합니다.
